## 📘 Project Overview

This Excel-based Financial Dashboard is built to transform raw business data into an interactive and visual report for quick decision-making. It includes charts, slicers, data validation, and an automated macro for PDF export — making it ideal for stakeholders, management, and reporting needs.

---

## 📂 Features

### ✅ 1. **Interactive Visualizations**

* **Clustered Column Charts**:

  * Sales & Profit Over Time
  * Sales & Profit by Segment
  * Total Discount by Month
* **Clustered Bar Chart**:

  * Units Sold by Month
* **Line Charts**:

  * Monthly Summary: Sales, Profit, and COGS
  * Profit vs Product

---

### ✅ 2. **Data Validation**

Used to ensure clean and consistent data entry in:

* **Segment**
* **Discount Band**
* **Units Sold**

Dropdowns improve data usability and reduce errors.

---

### ✅ 3. **Macro Automation**

Macro added:

* 📤 **Download**

  * A button-enabled macro exports the dashboard as a formatted PDF report with one click.

## ⚙️ Tools Used

| Tool                | Purpose                                           |
| ------------------- | ------------------------------------------------- |
| **Microsoft Excel** | Main platform for data analysis and visualization |
| **VBA (Macro)**     | For exporting dashboard as PDF                    |
| **Pivot Tables**    | Data aggregation for charts                       |
| **Slicers**         | Dynamic filtering                                 |

## 🚀 How to Use

1. Open the Excel file (`.xlsx`)
2. Use dropdowns and slicers to filter data
3. Analyze the visualizations
4. Click **"Download"** button to generate a report
